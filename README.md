Hemrock provides open-source finance software for founders and funds, offering financial models, AI‑assisted tools, workshops, and hands‑on help. Since 2005 the platform has served over 56 k founders and investors, delivering customizable models, data integrations, and community‑driven resources to streamline fundraising, budgeting, and financial planning.

**Areas:** Finance · Open-source · AI · Modeling · Community · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Hemrock: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
